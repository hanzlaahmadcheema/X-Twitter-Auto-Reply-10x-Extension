API Setup Guide

Welcome! To make the AI work, you need a secret "API Key" from one of our supported AI providers. It's completely free to get started. Choose your preferred AI below:

Google Gemini Recommended

1
Go to the Google AI Studio and sign in with your Google account.
2
Click the blue "Create API key" button.
3
Copy the generated long text string. Go back to the extension, select "Gemini", and paste it into the Authentication box!

Groq (Llama / Mixtral)

1
Go to the Groq Console and log in.
2
Click "Create API Key".
3
Copy the key, return to the extension, select "Groq", and paste it in!

X.ai (Grok)

1
Visit the X.ai Console.
2
Log in with your X (Twitter) account.
3
Navigate to the API Keys section, generate a key, and paste it into the extension.

OpenAI (ChatGPT)

1
Go to the OpenAI API Keys page.
2
Click "Create new secret key".
3
Copy the key immediately (you won't be able to see it again) and paste it into the extension.

Eden AI

1
Sign up at Eden AI.
2
Find your API Key on the main Dashboard or Settings page.
3
Copy and paste it into the extension.

Ollama (Local AI)

1
Download and install Ollama on your computer.
2
Open your terminal/command prompt and run ollama run llama3 to download a model.
3
Ollama runs locally at http://127.0.0.1:11434. Just select Ollama in the extension and you're good to go! No API key needed.
